# moyenne-monbureaunumerique.fr-moyenne-pour-mbn
un simple script en javascript pour calculer la moyenne sur mbn via une extension
ce projet permet de calculer la moyenne générale sur monbureaunumérique.fr.
Je me suis largement inspiré de https://github.com/NonozgYtb/mbn-enhancement-suite

Installation
Installer ou vérifier que les extensions (sauf pour Opéra) que vous pouvez ajouter un script JS coté utilisateur.

CHROME: Installer [TamperMonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo).
FIREFOX: Installer [GreaseMonkey](https://addons.mozilla.org/fr/firefox/addon/greasemonkey/).
IE: Installer [Trixie](http://www.bhelpuri.net/Trixie/).
OPERA: Regarder les instructions spécifiques pour Opéra: [Opéra User JS](http://www.opera.com/docs/userjs/).
SAFARI: Installer [NinjaKit](http://d.hatena.ne.jp/os0x/20100612/1276330696).

Utilisation
Il vous suffit de vérifier l'activation de l'extension et du script, et de se rendre sur MonBureauNumérique pour qu'il fonctionne.
